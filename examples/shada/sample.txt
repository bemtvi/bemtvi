nxvim shada — cross-session state that survives a restart
=========================================================

Run this file TWICE against a scratch state dir (see init.lua header):

  XDG_STATE_HOME=/tmp/nxvim-shada-demo NXVIM_CONFIG=examples/shada \
    cargo run -p nxvim -- examples/shada/sample.txt

needle in this haystack   <- :SeedShada pushes "needle" onto the / history
                             and drops global mark A on whatever line you ran it

FIRST session:
  :SeedShada    stash register "a, set global mark A, push the /needle search
  <space>w      :wshada — flush the store now (or just :qa, which flushes too)
  :qa           quit

SECOND session (same command — the state from session one is back):
  "ap           paste register "a from last session
  `A            jump to the global mark you set last session
  /<Up><CR>     recall last session's "needle" search
  :ShadaShow    print whether register "a was restored

Mid-session reconcile:
  <space>r / :rshada    re-read the store — picks up another nxvim instance's
                        state once that instance has exited (its file unlocks)
  :rshada!              overwrite a register you've already set this session
