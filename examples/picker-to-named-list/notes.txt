send / add to a list — the nx.qf.* API
=======================================

Usable on their own. Each takes an array of entry dicts
({ filename =, lnum =, col =, text = }) and an optional title:

  nx.qf.send_to_loclist(list, { title })   the window's loclist (vim split)
  nx.qf.add_to_loclist(list, { title })    APPEND to the window's loclist
  nx.qf.send_to_qflist(list, { title })    the global quickfix list
  nx.qf.add_to_qflist(list, { title })     APPEND to the quickfix list

A location list keeps vim behavior: a bottom split owned by its window, never a
dock tab. The quickfix list honors 'qfdock' (a bottom-dock tab by default, a
split with :set noqfdock).

For the dock-tab "save searches side by side" surface — what the picker's <C-q>
uses — see nx.qf.list / nx.qf.show (named lists) in init.lua section 2.

This second file exists so the "marks" picker and the location preview have more
than one file to jump between.
