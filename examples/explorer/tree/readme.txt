This is a sample directory tree for the nxvim file explorer.

You opened a directory, so nxvim listed it (vim's netrw). Move the cursor with
j / k, then press <CR> to open a file like this one. Opening a file replaces the
listing (it was just a picker). While in a listing, press `-` to go up a level.

Try descending into `src/` and opening one of the files there.
