btv.connect demo — a connector for the :connect command.

Open this in bemtvi with the example config, then run:

    :connect demo://here

The window reloads onto a local `bemtvi --daemon` (a daemon-backed session),
proving the connect → resolve → session-swap loop. Confirm with:

    :lua print(btv.daemon.status())   -- "connected"

See init.lua for the resolver and the full API notes.
