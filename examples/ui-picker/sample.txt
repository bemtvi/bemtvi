btv.picker sample buffer
=======================

Open a picker with one of the leader maps (leader is "\"):

    \ff   files       fuzzy file finder       (static, streams `rg --files`)
    \fg   live_grep   live grep               (dynamic, re-runs `rg` per key)
    \fb   buffers     pick an open buffer     (in-memory)
    \fc   colours     a custom static source
    \fe   echo        a custom dynamic source

Type to filter — the matched characters are highlighted, and the keystrokes
edit the picker's prompt, never this buffer. Move with <C-n>/<C-p>, confirm with
<CR>, cancel with <Esc>.

Try \fg and search for a word on this line: cornflower chartreuse cerulean.
