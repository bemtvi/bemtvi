btv.ui.input / btv.ui.confirm — the command-line prompt primitives.

Try the maps (leader is "\"):

  \i   btv.ui.input    — type a name, <CR> to submit, <Esc> to cancel
  \r   btv.ui.input    — prefilled with this file's name; edit or accept
  \d   btv.ui.confirm  — yes/no; y / <CR> confirms, n / <Esc> declines
  \q   btv.ui.confirm  — defaults to No on <CR> (the safe choice)
